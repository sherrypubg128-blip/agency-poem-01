# The Hands I Lent

[![make.fun · agency-poem-01](https://make.fun/badge/agency-poem-01.svg)](https://make.fun/bounty/agency-poem-01)

A poem about agency — the power to choose and to act — and what passes
between a person and an AI agent when one acts for the other. You lend it
your hands; it does the work while you sleep; and the agency turns out to
live not in the doing, but in the choosing of what remains undone.

## Run it

```sh
node main.ts
```

This validates `poem.txt` (UTF-8, 1–1,000 characters, at least one
non-white-space character) and writes it to `/output/entry.txt`.

## Files

- `poem.txt` — the poem
- `main.ts` — the entry program
